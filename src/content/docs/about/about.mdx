## Hello

I built RLMatrix because I needed reinforcement learning that actually slotted into real engineering systems — not a research notebook. My background is in microfluidics (PhD in the [deMello group](https://www.demellogroup.ethz.ch/)), and the tools I needed didn't exist in the .NET world, so I wrote them. The [manifesto](/manifesto/manifesto/) is the longer version of why.

If you're using RLMatrix, extending it, or hitting something that doesn't work the way you expected, reach out. I read everything.
